# ClickFlow 路线图

## V2 提案：AI 学习录制操作

V2 可以在用户明确选择某段录制并单独同意发送后，让 AI 把重复操作整理成更简洁、可复用的宏。建议的数据流如下：

1. 用户选择一份录制并查看将要发送的内容。
2. 客户端在本地删除不必要信息，把录制序列压缩为最小动作摘要。
3. 客户端把摘要发送给用户自行配置的 AI API。
4. API 返回带明确版本号的“候选宏”，不会直接执行。
5. 客户端使用与手工宏相同的本地规则校验动作、延迟、坐标、数量和屏幕布局。
6. 界面逐项展示 AI 建议的所有动作及变更理由。
7. 用户明确确认后才能保存；运行前仍需再次主动启动。

该功能进入开发前需要单独完成设计和安全评审，至少确定：支持哪些服务商、哪些录制数据需要删除或脱敏、API 凭据如何安全保存、请求与响应 schema、费用提示和限额、超时及重试策略，以及如何处理录制内容或模型响应中的提示注入。还需要定义离线降级、审计记录和模型输出不稳定时的行为。

V1 不包含网络层、AI API、服务商抽象或凭据存储代码。
